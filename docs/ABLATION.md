# Ablation (external games, held out)

Generated by `uv run more-than-a-hack-2027 ablate --seeds 0 1 2` (src/more_than_a_hack_2027/validation/ablation.py). Do not edit by hand.

- **Data:** Metrica Sports sample games 1, 2, 3 (github.com/metrica-sports/sample-data), with Metrica's event data turned into frame labels (a BALL LOST never starts a possession and a one-touch recovery is not one; external/metrica.py). The tracking is degraded to look like the competition ATD (ball smoothing and noise, player dropout, track fragmentation), using 3 degradation seeds. No BAR-ATH labels are used anywhere.
- **Held out:** each game is scored by a control model trained without it. The decoder settings stay at the v2 choice for every row, so read a drop as an upper bound on what the removed part is worth.
- **Numbers:** spellF1 and macroF1 are the official metric (evaluation/possession_metrics.py), averaged over 3 games × 3 seeds. *seed sd* is the spread of the 3-game mean across seeds. *90% interval* is a paired bootstrap of the difference from v2 (1000 draws over ground-truth possessions, the scorer's resampling unit). If it excludes 0, the gap is more than possession-sampling noise.
